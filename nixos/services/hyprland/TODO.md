## проверить на barnard

- Скриншот: выделение и рисование мышью, сохранение. Если монитор с масштабом не 1 — размер png.
- Блокировка: пароль через PAM, `loginctl lock-session` из меню power, блокировка перед сном.
- systemd: `sudo -A` спрашивает пароль в askpass и запускает или останавливает системный юнит.
- Переключатель vpn: v2rayN стартует и сам поднимает xray. Если нет — включить автозапуск ядра в v2rayN или запускать xray напрямую.
- Вкладки LibreWolf по `ctrl+,`: открывается наше меню вместо rofi.
- Run через xray (`alt+enter`): браузер и какое-нибудь Go-приложение реально идут через туннель.

## hyprland

- **Обои видно при смене тега**
  - Причина: `slidefade` гасит оба тега сразу.
  - Попробовать живьём, без пересборки:
    ```sh
    hyprctl dispatch 'hl.animation({ leaf = "workspacesOut", enabled = true, speed = 2.5, bezier = "out", style = "slide 6%" })'
    ```
  - Если мигает — `slide` для обоих.
- **Фуллскрин без hide/show заднего фона**
  - Найти, какая анимация у окон сзади, дать им `no_anim` или фейковый фуллскрин по классам.
  - У mpv теряется только direct scanout, качество то же.
- **Тема VeraCrypt**
  - Это wxWidgets/GTK3; под root он не видит пользовательский dconf.
  - Для Qt: `QT_QPA_PLATFORMTHEME` плюс qt6ct или kvantum с gruvbox.
