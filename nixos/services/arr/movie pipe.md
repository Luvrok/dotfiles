# Movie pipe

Фильмы и сериалы на barnard: нашёл в Kodi → нажал **Download…** → выбрал раздачу → через какое-то время фильм лежит в библиотеке с русскими субтитрами рядом, Kodi сам его отсканировал. Всё настроено декларативно в dotfiles, ничего не нужно настраивать руками в веб-интерфейсах.

```mermaid
flowchart LR
  K[Kodi<br>TMDb Helper] -- "Enter или c → Download…<br>(выбор раздачи)" --> R[Radarr / Sonarr]
  R -- поиск --> P[Prowlarr]
  P --> T4[1337x]
  P -. Cloudflare .-> F[FlareSolverr]
  P --> RP[rutracker-proxy] --> T1[rutracker]
  RP -. кука .-> F
  R -- ".torrent" --> Q[qBittorrent<br>без GUI]
  Q -- "/media/outer-1/downloads" --> R
  R -- "хардлинк, переименование" --> L["/media/outer-1/movies, series"]
  L --> B[Bazarr]
  B -- ".ru.srt / .en.srt" --> L
  B -- "английские, если нет русских" --> S[subtitles.py] --> J[subtitle-translator<br>на jedha] --> L
  L -- "скан папки" --> K
```

uindex и thepiratebay отдают только magnet-ссылки, поэтому выключены (`setup.py`): qBittorrent с ними навсегда висел бы на «Downloading metadata» — UDP и DHT здесь не работают. Остались rutracker и 1337x, оба отдают `.torrent`.

## Что где

| Что | Где | Зачем |
|---|---|---|
| qBittorrent (headless) | http://127.0.0.1:8140 | качает торренты Radarr/Sonarr, без логина с этой машины. GUI-qBittorrent не трогается |
| Radarr | http://127.0.0.1:7878 | фильмы: ищет, выбирает раздачу, переносит в `movies` |
| Sonarr | http://127.0.0.1:8989 | сериалы, то же для `series` |
| Prowlarr | http://127.0.0.1:9696 | трекеры, отдаёт их Radarr и Sonarr |
| Bazarr | http://127.0.0.1:6767 | субтитры ru и en |
| FlareSolverr | 127.0.0.1:8191 | проходит проверку Cloudflare («Just a moment…») для 1337x, даёт куку rutracker-proxy |
| rutracker-proxy | 127.0.0.1:8150 | rutracker через Cloudflare: [rutracker-cf-proxy](https://github.com/rofl3228/rutracker-cf-proxy), в Prowlarr — «RuTracker» |

Все веб-интерфейсы только на `127.0.0.1`, снаружи их не видно. В файрволе открыт только порт пиров qBittorrent (51413 TCP/UDP).

Код:

- `nixos/services/arr/default.nix` — сервисы
- `nixos/services/arr/setup.py` — настройка через их API (сервис `arr-setup`, на каждой загрузке и switch)
- `nixos/services/arr/subtitles.py` — перевод субтитров
- `nixos/services/arr/shared.nix` — порты и пути
- `nixos/services/kodi/moviepipe/` — аддон Kodi «Movie pipe»
- `nixos/services/kodi/addons.nix` — все аддоны Kodi

## Один раз: логины

Логины лежат в `secrets/arr.yaml` (sops, как остальные секреты). Все необязательные: без файла пайплайн работает, просто без rutracker, opensubtitles.com и перевода.

```sh
sops secrets/arr.yaml
```

```yaml
rutracker_username: логин
rutracker_password: пароль
# бесплатный аккаунт opensubtitles.com, там большинство русских субтитров
opensubtitles_username: логин
opensubtitles_password: пароль
# ключ LibreTranslate на jedha, тот же, что вводишь на странице subtitle-translator
libretranslate_key: ключ
```

```sh
git add secrets/arr.yaml   # flake видит только файлы в git
sudo nixos-rebuild switch --flake .#barnard
```

После смены файла `arr-setup` перезапускается сам и вписывает логины в Prowlarr и Bazarr.

> [!note] RuTracker
> rutracker закрыт проверкой Cloudflare, туда ходит `rutracker-proxy` (кука от FlareSolverr, запросы как от того же Chrome). Если сам rutracker попросит капчу при входе, Prowlarr покажет её картинкой в Indexers → RuTracker → Test. Или войди один раз на rutracker в браузере с barnard.

## Каждый день

### Найти и скачать

Правило: **ничего не качается без выбора раздачи.** Отдельного «Download» с автопоиском больше нет — везде одно действие **Download…**, оно открывает окно раздач.

- `5` — **Discover**, как раздел главной Majan. Сверху — постер в фокусе: ряд, название, «год · 2h 16m · 7.7 / 10 · жанры», описание, картинка. Снизу по два ряда, при ↓ подъезжают следующие:
  - *Downloading* — что качается сейчас (Enter — окно загрузок);
  - *Trending this week*, *Popular*, *In cinemas* / *On the air*, *Upcoming* / *Airing today*, *Top rated*;
  - *Because you have …* — рекомендации к последнему фильму или сериалу библиотеки;
  - *Popular people*.

  Последняя плитка ряда — стрелка **NEXT**: Enter листает этот ряд на следующие 20 на месте, ← на первой плитке — назад (и в рядах под полосой на главной). Описание сверху обрезается по строкам, лишнее затемняется; ↑ из рядов — фокус на описании, Enter — целиком. `o` — страница постера на TMDb в браузере. Чипы в полосе заголовка (↑ из рядов): **MOVIES** / **TV SHOWS**, **SEARCH** (поиск по TMDb: ряды Films, TV shows, People; Back — обычные ряды), **ALL OF TMDB HELPER** (старый список папок). Ряды грузятся по мере прокрутки, пустые прячутся, пока ряд грузится, старые постеры притушены.
- На главной в верхней полосе **04 Live TV**, **05 Discover**, **06 Downloads**: фокус на пункте (мышь тоже) показывает под полосой его ряды — каналы, тренды TMDb, что качается; Enter — его окно.
- Enter на фильме (Discover, TMDb Helper, страница человека) — **Movie pipe: Download…** (у фильма из библиотеки там же «Play with Kodi»). Enter на сериале — его страница, на человеке — его страница.
- `c` на фильме, сериале, сезоне или серии → **Download…** — окно раздач.
  - сериал — спросит, какие сезоны; потом окно раздач **для каждого сезона по очереди** (Esc на одном — переходит к следующему). Сезон, для которого ничего не выбрал, не остаётся «wanted» в Sonarr — сам он его не скачает;
  - сезон или серия в TMDb Helper — раздачи именно их.
- Поиск раздач идёт **в фоне**: полоска в углу, Kodi можно пользоваться; окно выбора откроется само, когда трекеры ответят.
- `c` → **Delete from disk** на фильме, сериале, сезоне или серии из библиотеки — с подтверждением. Удаляет Radarr/Sonarr (у них есть права на диск, у Kodi нет), вместе с файлами: фильм или сериал убирается из Radarr/Sonarr целиком, у сезона или серии удаляются файлы и снимается «wanted» — заново они не скачаются. Kodi сразу убирает их из библиотеки.
- Окно раздач: строка — название, под ним серым колонки: качество (`BDRip 1080p` — лучшее в профиле — выделено белым), SDR / HDR, размер, сиды, трекер, релиз-группа, язык (`RU` — русская озвучка), возраст и «why ✗» (весь интерфейс по-английски). По умолчанию сверху SDR, внутри — в порядке Radarr/Sonarr: сначала те, что они взяли бы сами. `●` — та, которую они выбрали бы сами. `✗` — не взяли бы, коротко почему — в последней колонке (`HDR`, `quality not in profile` — качество не из профиля, `few seeders`, `already downloading`, `unknown title`…), полностью — под списком; выбрать можно любую. Названия колонок — кнопки, как в таблице: ↑ с первой строки (или k) переходит на них, ← → между ними, Enter сортирует по колонке, ещё раз — в обратную сторону. Последняя кнопка, «search», оставляет раздачи с текстом в названии, группе, трекере или качестве (например, `playweb`); пустой поиск — снова все. Раздачи других фильмов с тем же названием всегда в самом низу. Esc — ничего не добавляется.
- `6` — окно загрузок, обновляется каждые 2 секунды: состояние, полоска, %, скачано, скорость, сиды (подключено и всего в раздаче, по qBittorrent), сколько осталось, качество, SDR / HDR, трекер. Под списком — полное имя раздачи и ошибки. Справа в строке кнопка ⏸ / ▶: → (l) на неё и Enter, или пробел на строке — пауза или старт в qBittorrent; ← (h) обратно на строку. Enter на строке: **Pause** / **Resume**, **Another release** (эта в чёрный список, ищет следующую) или **Remove**. `v` — отметить строку (✓, фокус уходит на следующую), `d` — убрать отмеченные (или строку в фокусе, если ничего не отмечено), с подтверждением; `r` — обновить сразу. Его же открывает Movie pipe в «Дополнениях».

SDR / HDR берётся из названия раздачи: `DV` (Dolby Vision; без `HDR10` рядом — только DV), `HDR10`, `HDR10+`, `HDR`, `HLG`, `SDR`. Без пометок: до 1080p — `SDR` (BDRip 1080p — рип обычного Blu-ray, а он всегда SDR; HDR бывает только на UHD Blu-ray), у 2160p — `HDR?` (может быть и то и другое, смотри полное название).

`no peers` и `0 (113)` в сидах — у раздачи 113 сидов, но qBittorrent ни к одному не подключился. Если так долго — проверь, что qBittorrent видит трекер: http://127.0.0.1:8140 → раздача → Trackers.

Kodi показывает уведомления: «Downloading…», «Downloaded…», «Download failed…». Когда фильм перенесён в библиотеку, Kodi сканирует только его папку — фильм появляется сам. Если Kodi был выключен, он догонит при запуске.

**Download…** есть на фильмах не из библиотеки и на любых сериалах (в том числе из библиотеки — докачать новый сезон), **Delete from disk** — на всём из библиотеки.

### Страница фильма: актёры, режиссёр, похожие

- Ряд актёров внизу страницы фильма или сериала — из TMDb (TMDb Helper), а не из библиотеки. Enter на актёре — страница человека. Пока актёры грузятся, в ряду «Loading the cast…». Если TMDb Helper не успел (обычно первые открытия после запуска Kodi), Movie pipe сам запрашивает ряд ещё раз через 3 секунды, до трёх раз; не вышло — «No cast on TMDb», `r` на странице — ещё раз.
- More → **MORE BY DIRECTOR** — страница режиссёра (не своя библиотека). Режиссёр берётся из съёмочной группы фильма на TMDb (по tmdb id), так что кнопка есть и у фильмов из списков TMDb Helper, где режиссёра в карточке нет. У сериала — создатель.
- **Страница человека** (как страница фильма Majan): фото, имя, чем известен, дата рождения, возраст, откуда, сколько фильмов и сериалов, биография (стоит на месте; если она длиннее шести строк, под ней подсказка, Enter на ней — целиком). Под ней строка как ряд More: вкладки **FILMS** / **TV SHOWS** / **DIRECTED** и порядок **POPULAR** (самые известные сверху) / **NEWEST** / **OLDEST**, ← → между ними, выбранные подчёркнуты. При переключении старый ряд сразу убирается, на его месте «Loading…». ↓ — ряд постеров (страница уезжает вверх). Enter на фильме — **Download…**, на сериале — его страница; `i` — страница, `c` — меню, `t` — трейлер, `r` — загрузить ряд заново. По 60: последняя плитка **Next page ›**, ← на первой — предыдущая страница. Актёр открывается на фильмах (на сериалах, если открыли из сериала), режиссёр — на Directed.
- В списках нет пункта «..» (Back) — назад клавишей `q`.
- More → **TMDB ↗**, **IMDB ↗**, **LETTERBOXD ↗** — страница фильма или сериала в браузере (`xdg-open`), чтобы сразу добавить себе. На странице человека — чип **TMDB ↗**, на постерах — `o`.
- Описание на странице фильма и биография человека не прокручиваются сами: что не влезло, затемняется, Enter на них — целиком.
- **Просмотрено** ставится только руками: `w` (или `c` → Mark as watched). Kodi сам ничего не отмечает — ни после mpv, ни в своём плеере.
- **Trailer** есть и у фильмов из TMDb Helper: если у фильма нет своего трейлера, играет первый трейлер TMDb (YouTube) в mpv.
- More → **SIMILAR** — рекомендации TMDb к этому фильму или сериалу.

### Клавиши

- `g` / `G` — первый / последний элемент списка. `shift+буква` больше не прыгает к элементу на эту букву.
- `r` — перезагрузить список (в окнах Movie pipe — их ряды, на странице фильма — актёров).
- Клавиши работают и на русской раскладке: Kodi собран с патчем `nixos/services/kodi/kodi-keys.patch` — клавиша берётся с первой раскладки (us), а символ в поле ввода остаётся русским. Из-за патча Kodi собирается из исходников (дольше при обновлении nixpkgs).

### Какие раздачи берутся

Профиль качества **BDRip 1080p** (Radarr и Sonarr):

1. Bluray-1080p (BDRip) — лучший
2. 4K (2160p): BDRip, Remux, WEB-DL — только не HDR
3. WEB-DL 1080p
4. 720p (WEB-DL, BDRip) — только если ничего выше нет; потом заменится на 1080p или 4K, когда появится
5. Не берутся автоматически: WEBRip (поток, записанный и пережатый ещё раз — хуже WEB-DL, который сам файл сервиса), HDR в любом качестве, Remux 1080p, BR-DISK, CAM / TS, DVD

Минимальный размер — чтобы не брать пережатое, что видно на большом экране (2 ГБ на фильм 1080p): 1080p — 25 МБ на минуту (фильм на 2 часа — от 3,6 ГБ), 4K — 60 (от 7,2 ГБ), 720p — 12. Меньше — `✗ слишком маленькая`. WEB-DL 1080p обычно 30–60 МБ/мин.

HDR — по названию раздачи: `HDR`, `HDR10`, `HDR10+`, `DV` / `Dolby Vision`, `HLG` (пользовательский формат «HDR», оценка −10000 при минимуме 0). 4K без пометок пройдёт, хотя может оказаться HDR — в окне выбора у него `HDR?`. 4K-рипы и ремуксы с UHD Blu-ray почти всегда HDR, так что 4K SDR — в основном WEB или раздачи с пометкой `SDR`.

Среди одинаковых по качеству выигрывает русская озвучка (+10 к оценке), потом трекер по приоритету: rutracker → 1337x, потом больше сидов. Скачанные WEB-DL 1080p и 4K уже не меняются на BDRip 1080p. uindex и thepiratebay выключены: у них только magnet.

Radarr ищет на трекерах по названию без года: у фильма, показанного на фестивале годом раньше, на трекерах часто тот год (Obsession: на TMDb 2026, премьера на TIFF в 2025). Подходящими он считает оба года — выхода и премьеры, фильмы с тем же названием и другим годом отбрасывает.

Имена: `Фильм (2010) {tmdb-27205} [Bluray-1080p].mkv`, сериалы `Сериал (2008) {tmdb-1396}/Season 01/Сериал - S01E01 - Название [WEBDL-1080p].mkv`. `{tmdb-…}` Kodi читает и находит точный фильм на TMDb без поиска по названию.

### Раздача и место

Торренты качаются в `/media/outer-1/downloads`, в библиотеку попадают хардлинками — место не удваивается, раздача продолжается. До рейтинга 2 или 30 дней, потом qBittorrent останавливает торрент, Radarr/Sonarr его удаляют из `downloads`. В библиотеке файл остаётся.

### `.torrent`, не magnet

Radarr и Sonarr берут у Prowlarr ссылку на `.torrent` и отдают qBittorrent уже файл, со списком файлов внутри. Поэтому `Downloading metadata` не появляется: метаданные не надо тянуть у пиров.

- у всех трекеров `Prefer Magnet URL` выключен;
- у 1337x `Primary` и `Fallback Download link` — `iTorrents`, а не magnet;
- uindex и thepiratebay выключены: у них в результатах только magnet, `.torrent` нет.

Почему magnet висит: метаданные у него не в файле, их надо скачать у пиров через DHT/PeX или по трекерам. С barnard DHT-bootstrap (`dht.transmissionbt.com:6881`, `router.bittorrent.com:6881`, `dht.libtorrent.org:25401`) не отвечает, большинство UDP-трекеров тоже, поэтому DHT показывает 2–5 нод и метаданные не приходят. Настройками qBittorrent это не лечится: `BTProtocol = "TCP"` в `default.nix` только убирает бесполезный uTP, пиров он не добавляет. Рабочий путь здесь — `.torrent`; если у раздачи только magnet, она останется на `Downloading metadata`.

Если в qBittorrent у нового торрента пустой `magnet_uri` и сразу есть файлы — всё правильно. Старые торренты, добавленные магнитом, так и останутся на `Downloading metadata`: их надо удалить и перезабрать.

## Субтитры

Bazarr ищет для каждого нового фильма и серии **русские и английские** (профиль «Russian, English»). Русские не ищутся, если в видео есть русская дорожка.

Провайдеры: opensubtitles.com (нужен аккаунт), YIFY (фильмы), TVsubtitles (сериалы), embeddedsubtitles — достаёт дорожки субтитров из самого видео в отдельный файл.

Перевод (`subtitles.py`):

1. Bazarr скачал английские → кладёт их в очередь `/var/lib/arr/subtitles`.
2. Через 2 минуты (Bazarr за это время успевает найти русские, если они есть) проверка: есть ли рядом `.ru.srt`, русская дорожка или русские субтитры внутри видео. Есть — ничего не делает.
3. Нет — отправляет английские на subtitle-translator jedha (LibreTranslate): сначала через `jedha-tunnel` (`127.0.0.1:5390`), если не отвечает — через `lt.vxrnt.ru`.
4. Результат кладёт рядом с видео как `Фильм….ru.srt`. mpv подхватывает его сам.

Файлы по одному, сезон сериала переводится по серии. Ошибка (jedha выключен) — повтор через 30 мин, 1 ч, 2 ч… всего 6 попыток. Переведённые Bazarr считает русскими и больше русские для этого видео не ищет.

## Прокси

Radarr, Sonarr, Prowlarr и Bazarr ходят в интернет через xray (`127.0.0.1:10808`), qBittorrent — никогда; напрямую только локальная сеть и `127.0.0.1`. Причина: серверы Prowlarr (описания трекеров, проверка FlareSolverr), Radarr и Sonarr стоят за Cloudflare, а провайдер его режет — напрямую Prowlarr не мог скачать описания uindex, TPB и 1337x. Пока xray выключен, поиск не работает. Выключить: `useProxy = false;` в `nixos/services/arr/default.nix`. Для самого Kodi (постеры TMDb) — свой `useProxy` в `nixos/services/kodi/default.nix`.

## ТВ

`4` — каналы. Списки бесплатных каналов iptv-org: «Russia» (Первый, Россия 1, НТВ и другие) и «News» (новости со всего мира: LiveNOW from FOX, CBS News, Bloomberg, Sky News, DW…). Сам Fox News Channel платный, бесплатно его нет. ТВ и стримы играют во встроенном плеере Kodi, файлы библиотеки — в mpv.

## Если что-то не так

```sh
systemctl status arr-setup radarr sonarr prowlarr bazarr qbittorrent flaresolverr
journalctl -u arr-setup -b       # что настроилось, что нет; при ошибке сам повторит через 30 мин
journalctl -u arr-subtitles -f   # перевод субтитров
ls /var/lib/arr/subtitles        # очередь перевода
journalctl -u radarr -f          # поиск и импорт фильмов
```

- Ничего не находит — Prowlarr → Indexers → Test all. Красный 1337x — FlareSolverr (`journalctl -u flaresolverr`); всё красное — xray (v2rayN) выключен. uindex и thepiratebay выключены намеренно (только magnet).
- Торрент висит на «Downloading metadata» — он пришёл магнитом: проверь `magnet_uri` у него (`curl -s 127.0.0.1:8140/api/v2/torrents/info`), удали и перезабери. Новые должны быть с пустым `magnet_uri` и списком файлов сразу.
- Красный RuTracker — `curl -s 127.0.0.1:8150/health` (есть ли кука Cloudflare, `last_error`) и `journalctl -u rutracker-proxy`. Капчу на входе Prowlarr показывает картинкой: Indexers → RuTracker → Test, ввести код. Или один раз войти на rutracker в браузере с barnard.
- «radarr не ответил за 150 с» или ошибка при **Download…** на новом фильме — Radarr не дождался своего сервера фильмов (api.radarr.video, ходит через xray): `journalctl -u radarr -b -n 200` — первая строка ошибки перед `SkyHookProxy`. Повтори через минуту; если так всегда — xray.
- Скачалось, но нет в Kodi — Radarr → Activity → Queue (ошибка импорта), или `f` в Kodi.
- Нет субтитров — Bazarr → Wanted / History.
- Переводчик: `curl -s http://127.0.0.1:5390/subtitle-translator/api/languages` должен вернуть список языков. `LibreTranslate unreachable` — на jedha лежит LibreTranslate (`systemctl status libretranslate`).
- Настройки из веб-интерфейсов не трогаются, кроме тех, что задаёт `setup.py` (профиль, клиент загрузок, именование, трекеры, языки Bazarr) — их он вернёт на следующем запуске.
